# مراجعة الواجهة وتجربة الاستخدام (UI/UX)

مرجع التقييم: [Material Design 3](https://m3.material.io/)، و[إرشادات الوصول WCAG 2.1](https://www.w3.org/TR/WCAG21/)، و[Nielsen's 10 Heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/).

**المستخدم المستهدف:** موزّع في الشارع، يمسك الجوال بيد واحدة، بين بقالة وأخرى، وأحياناً في ضوء الشمس أو ليلاً. مستواه التقني متوسط أو بسيط. **أولويته: السرعة وعدم الخطأ.**

## ما تم تطبيقه

### السهولة: أي شخص يفهمه

| المبدأ | التطبيق |
|---|---|
| لغة المستخدم (Nielsen #2) | "عطاء"، "الباقي عليه"، "له رصيد"، "في جيبك" بدل "مدين" و"دائن" و"رصيد محاسبي" |
| رقم واحد واضح | كل بقالة لها رقم واحد: **الباقي**. لا تقسيم للدفعات على الأيام (انظر ADR-0004) |
| يوم العمل هو الهيكل | الشاشة الرئيسية = اليوم، فيها وضعان فقط: عطاء (صباح) وتحصيل (ليل) |
| الوضع الصحيح تلقائياً | بعد العصر يفتح وضع التحصيل مباشرة |
| أول تشغيل موجّه | 3 خطوات + أصناف جاهزة + خيار بيانات تجريبية، بدل شاشة فارغة |
| ترتيب خط السير | البقالات بنفس ترتيب طريقه اليومي (سحب وإفلات) |

### السرعة: أقل عدد ضغطات

| المهمة | الضغطات |
|---|---|
| تسجيل عطاء (صنفان) | بقالة ← `+1` ← `+½` ← حفظ = **4** |
| تحصيل المبلغ كاملاً | بقالة ← "كامل المطلوب" ← تسجيل = **3** |
| استلام الصباح | الكميات تُعبّأ من آخر استلام ← حفظ = **2** |

- أزرار الكسور `+¼ +½ +1` مناسبة لبيع الكراتين الجزئية.
- `−` يتراجع بنفس مقدار آخر زيادة (لو ضغطت +½ بالخطأ، `−` يطرح ½ وليس 1).
- اختصارات المبالغ: كامل المطلوب، عطاء اليوم فقط، النصف.

### الدقة: منع الأخطاء (Nielsen #5) والتعافي منها (#9)

- **تراجع** بعد أي حذف (Snackbar لمدة 5 ثوانٍ)، بدل نوافذ "هل أنت متأكد؟" المزعجة للأفعال القابلة للعكس.
- **تأكيد** فقط للأفعال الخطيرة: حذف بقالة كاملة، ومسح كل البيانات (تأكيد مزدوج).
- **تنبيه عند الخروج بدون حفظ** من شاشة العطاء.
- **"الباقي بعد الدفع" يظهر لحظياً** أثناء كتابة المبلغ، فيرى النتيجة قبل الحفظ.
- **سعر خاص** يظهر بلون مختلف + "(سعر خاص)"، فلا يمر سعر خاطئ بدون انتباه.
- **البضاعة في السيارة**: تنبيه أحمر لو وُزّع أكثر مما استُلم.
- **تقبّل الأرقام العربية والفارسية والإنجليزية** والفواصل في كل الحقول.

### الوضوح البصري

- **تباين ألوان مقاس ≥ 4.5:1** (WCAG AA) لكل الألوان الدلالية على الأبيض: عليه 5.6، له 5.8، مسدّد 5.1، تنبيه 4.6 (كان 3.1 وتم تصحيحه).
- **ترميز لوني ثابت** في كل التطبيق: 🔴 عليه · 🔵 له · 🟢 مسدّد · 🟠 مرتجع أو تنبيه، ودائماً مع نص ("عليه"/"له")، فلا يعتمد الفهم على اللون وحده (WCAG 1.4.1).
- **خط عربي احترافي** (IBM Plex Sans Arabic) بدل خط النظام الافتراضي. أوضح للأرقام والكسور.
- **أرقام بعرض ثابت** فلا تقفز الأعمدة.
- **عزل اتجاه النص** للكسور والأرقام السالبة داخل النص العربي (`1½` لا تنقلب إلى `½1`، والإشارة `-` في مكانها).
- **أهداف لمس ≥ 46dp** (المعيار 48dp، والهامش مقبول بفضل التباعد).
- **ثلاثة أحجام للخط + وضع ليلي** لضوء الشمس والليل.
- **اهتزاز خفيف** عند الحفظ والتحصيل وتبديل التبويب (قابل للإيقاف).

### التنقل

- 5 تبويبات سفلية (حد Material الأعلى) للوصول بالإبهام.
- زر الرجوع في أندرويد يعيد من أي تبويب إلى "اليوم" قبل الخروج.
- الضغط المطوّل على بطاقة بقالة يفتح كشف حسابها.
