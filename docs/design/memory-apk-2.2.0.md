### الفرق عن 2.1.0 (19.7 MB ← 26.6 MB)
**+4.9 MB = ماسح الباركود (ML Kit مدمج يعمل بلا إنترنت).** البديل (ML Kit عبر Google Play Services) يوفّرها لكنه يحتاج تنزيلاً عند أول استخدام ولا يعمل على جوالات بلا GMS — اخترنا المدمج للموثوقية.

### إجراءات التقليص المفعّلة
- R8 minify + shrinkResources + ProGuard.
- `localeFilters = ar, en` (حذف موارد ~80 لغة).
- Tree-shaking لأيقونات Material (تبقى المستخدمة فقط).
- APK مقسّم حسب المعمارية (الجوال يحمّل نسخته فقط: لا 54 MB universal).
