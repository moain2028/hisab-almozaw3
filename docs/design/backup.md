# النسخ الاحتياطي والاسترجاع

## ثلاث طبقات حماية

| الطبقة | أين | متى | يحمي من |
|---|---|---|---|
| 1. قاعدة البيانات | `app_flutter/*.hive` (داخلي، خاص بالتطبيق) | فوراً مع كل تعديل | إغلاق التطبيق، انقطاع البطارية |
| 2. **نسخ محلي تلقائي** | `Android/media/com.hisabalmozaw3.distributor/Backups/` | بعد 8 ثوانٍ من آخر تعديل + عند الخروج + عند الفتح | حذف التطبيق، تلف قاعدة البيانات، خطأ المستخدم |
| 3. خارج الجوال | واتساب / تلجرام / Drive (زر مشاركة) + نسخ Google التلقائي | يدوياً / يومياً من النظام | ضياع الجوال أو كسره |

## لماذا `Android/media`؟ (نفس اختيار واتساب)

- **يبقى بعد حذف التطبيق.** المجلد `Android/data/<pkg>` يُحذف مع التطبيق، أما `Android/media/<pkg>` فيبقى. لهذا تجد واتساب يسترجع المحادثات بعد إعادة التثبيت.
- **لا يحتاج أي إذن تخزين** على أي إصدار أندرويد (نظام Scoped Storage يسمح للتطبيق بالكتابة في مجلده داخل media).
- **ظاهر في مدير الملفات**، فيمكن نسخه للكمبيوتر أو لذاكرة خارجية.
- **احتياط:** إن تعذّرت الكتابة (جهاز نادر)، ينتقل الحفظ تلقائياً لمجلد مستندات التطبيق الداخلي.

> ملاحظة: عند إعادة التثبيت تعرض شاشة أول تشغيل: "وجدنا X نسخة احتياطية على الجوال، استرجع حساباتك". هذه نفس تجربة واتساب.

## صيغة الملف `.hisab`

```
GZip(
  {
    "format": "hisab-backup",
    "v": 1,
    "sha256": "<بصمة payload>",
    "payload": "<JSON كامل: shops, products, traders, shopTxs, traderTxs, expenses, settings>"
  }
)
```

- **GZip**: الملف أصغر بأكثر من 3 مرات من JSON الخام (يتحقق منه اختبار).
- **SHA-256**: قبل أي استرجاع نعيد حساب البصمة. لو اختلفت يُرفض الملف ولا يتغير شيء.
- **متوافق للخلف**: نقبل أيضاً JSON خام (نسخ "كنص" والإصدارات القديمة).
- **رقم الإصدار** `version` داخل البيانات: ملف من إصدار أحدث من التطبيق يُرفض برسالة واضحة.

## ضمانات السلامة

| الخطر | الحماية |
|---|---|
| انقطاع أثناء كتابة النسخة | كتابة في `.name.tmp` ثم `rename` ذري. النسخة السابقة لا تُلمس |
| ملف تالف أو معدّل | فحص SHA-256 قبل الاسترجاع |
| استرجاع خاطئ يمسح الحسابات | **نسخة أمان تلقائية** `hisab-before-restore-*.hisab` قبل أي استبدال |
| فشل في منتصف الاستيراد | التحويل والتحقق من **كل** السجلات قبل لمس قاعدة البيانات |
| تراكم الملفات | تدوير: نسخة تلقائية واحدة لكل يوم (تُستبدل خلال اليوم)، آخر 14 يوماً، و20 نسخة يدوية |
| نسخ مكرر بلا تغيير | يُقارن مرجع البيانات (عدد السجلات + طابع آخر تعديل) بمرجع آخر نسخة |

## الاسترجاع

- **من القائمة:** المزيد ← النسخ الاحتياطي على الجوال ← اضغط النسخة. يُعرض ملخص (عدد البقالات والحركات) قبل التأكيد.
- **من ملف آخر:** "استرجاع من ملف آخر"، ثم اختر ملف `.hisab` الذي نزّلته من واتساب.
- **الوضعان:**
  - *استبدال*: يرجّع الحالة كما كانت في النسخة (مع نسخة أمان للحالي).
  - *دمج*: يضيف ويحدّث بالمعرّف (UUID) بدون حذف.

## نسخ Google التلقائي (طبقة إضافية مجانية)

`AndroidManifest.xml` يفعّل `allowBackup`، و`res/xml/data_extraction_rules.xml` يحدد مجلد `app_flutter/` (ملفات Hive):
- يُنسخ لحساب Google يومياً عند الشحن والاتصال بالواي فاي (أندرويد 6+).
- ويُنقل تلقائياً عند الانتقال لجوال جديد (device-transfer، أندرويد 12+).
