# 0004 — رصيد جارٍ واحد بدل توزيع الدفعات على الأيام
## السياق والمشكلة
المشروع الأصلي كان يوزّع كل دفعة "من أحدث يوم للأقدم" ويحمل رصيداً زائداً للأمام. الناتج أرقام لكل يوم (مسدّد/متبقٍ) يصعب على الموزع فهمها أو مطابقتها مع صاحب البقالة.
## القرار
رصيد جارٍ واحد لكل بقالة: `سابق + عطاء − مرتجع − خصم − تحصيل`. الكشف يعرض الرصيد بعد كل حركة. وهذا هو الدفتر الورقي الذي يعرفه الموزع.
## العواقب
- ✔ رقم واحد واضح: "الباقي عليه"؛ مطابقة سهلة؛ حساب أبسط وأسرع.
- ✘ لا يجيب مباشرة على سؤال "أي يوم لم يُسدَّد؟". البديل المعروض: "آخر دفعة" + ترتيب "المتأخرين".
