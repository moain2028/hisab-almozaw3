# ADR 0012 — APK مضغوط للتنزيل (المكتبات تُفك عند التثبيت) + Zopfli

- الحالة: مقبول (2.4.0) — طلب المستخدم «ينضغط بقوة عند التنزيل ويُفك عند التثبيت».
- القرار:
  1. `packaging.jniLibs.useLegacyPackaging = true` (Gradle) ⇒ `extractNativeLibs=true`: محرك Flutter وكود التطبيق **مضغوطان** داخل الـ APK، ومثبّت أندرويد يفكّهما مرة واحدة عند التثبيت.
  2. `tool/zopfli_apk.py`: إعادة ضغط كل الإدخالات بـ **Zopfli** (أقوى Deflate قياسي — يفكّه أي جوال) ثم `zipalign -P 16` ثم التوقيع بنفس المفتاح. `resources.arsc` يبقى غير مضغوط (إلزامي Android 11+).
- لماذا ليس ضغطاً أقوى (xz/brotli/7z)؟ مثبّت أندرويد يقرأ **Deflate فقط**. أي صيغة أخرى = «لم يتم تثبيت التطبيق». الطريق الوحيد الآخر «مُثبّت ذاتي يفك الملف» = تطبيقان + أذونات + سلوك يشبه البرمجيات الخبيثة ⇒ مرفوض.

## القياس (arm64، بايت)
| | التنزيل | على الجوال بعد التثبيت |
|---|---|---|
| 2.3.1 (مكتبات غير مضغوطة) | 19,331,012 | ≈ 19.3MB (يُشغَّل من الـ APK) |
| 2.4.0 مضغوط (Gradle) | 9,448,928 | ≈ 9.4 + 17.4 = 26.9MB |
| **2.4.0 + Zopfli (المنشور)** | **9,112,507** (−52.9%) | ≈ 9.1 + 17.4 = 26.5MB |

armv7: 16,872,030 ← **8,772,549** (−48.0%)؛ مكتبات مفكوكة 14.97MB.

- **الثمن:** مساحة الجوال بعد التثبيت أكبر بـ ~7MB (نسخة مفكوكة من المكتبات) — هذا معنى «يرجع حجمه» الذي طلبه المستخدم.
- الإقلاع: لا فرق (الفك مرة واحدة عند التثبيت).
- التحقق المنفّذ: `apksigner verify` (نفس الشهادة C7:DD:99…)، `zipalign -c -P 16`، `unzip -t`، مقارنة محتوى كل ملف بايت-ببايت مع ناتج Gradle = 0 فروق، `aapt2 dump badging` سليم.
- **لم يُتحقق:** تثبيت فعلي على جوال (لا يوجد محاكٍ/KVM في بيئة البناء).
- التراجع: احذف كتلة `packaging { jniLibs { … } }` ولا تشغّل zopfli_apk.py.
