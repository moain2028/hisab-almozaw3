# ADR 0007 — شريط سفلي للعمل اليومي + قائمة جانبية + زر إعدادات

- الحالة: مقبول (2.2.0) — يحل محل تبويب «المزيد».
- القرار: الشريط السفلي 4 وجهات يومية فقط (اليوم، البقالات، التاجر، التقارير). القائمة الجانبية للبيانات والأدوات (الأصناف، إضافة بقالة، المصاريف، النسخ، التحديث) والإعدادات في آخرها. زر ⚙ في رأس كل شاشة رئيسية.
- السبب: «المزيد» يخلط إعدادات بأدوات ويخفي وظائف مهمة؛ كل وجهة الآن في مكان واحد متوقع.
