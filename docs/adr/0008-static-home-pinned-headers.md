# ADR 0008 — رئيسية ثابتة + رؤوس مثبّتة بارتفاع المحتوى

- الحالة: مقبول (2.3.0).
- القرار: الرئيسية بلا قوائم طويلة (بطاقة بطلة + شبكة إجراءات 3×2 + تقدّم اليوم). القوائم في صفحاتها (سجل اليوم، البقالات، التاجر، التقارير) وأدوات التحكم فيها في رأس مثبّت `PinnedHeader`.
- التنفيذ: `PinnedHeader` مبني على `PinnedHeaderSliver` (ارتفاع يُقاس من المحتوى). رُفض `SliverPersistentHeader` بارتفاع ثابت لأنه أنتج overflow حتى 173px بخط ×1.25 (كشفه `ui_audit_test`).
- السبب: شكاوى «التطبيق يشبه صفحة ويب»؛ أدوات البحث/الفلترة كانت تختفي عند التمرير.
- النتيجة: 0 overflow على 3 مقاسات × خطّين × وضعين.
