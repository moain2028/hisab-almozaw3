# ADR 0006 — الترخيص عن بعد بهاش الكود

- الحالة: مقبول (2.2.0)
- القرار: `license.json` عام فيه `active`, `codeHash`, `message`. الكود الحقيقي **لا يُنشر**؛ المنشور `sha256("hisab-almozaw3:" + CODE)` فقط، والكود في مستودع خاص.
- القواعد: active=true يفتح · false يقفل ويطلب الكود · تغيير الهاش يعيد القفل · حذف الملف بعد رؤيته = قفل نهائي · بلا إنترنت = آخر حالة معروفة · أول تشغيل بلا نت = مفتوح.
- الأمان: القفل يمنع الواجهة فقط؛ البيانات والنسخ الاحتياطي لا تُمس. الإقلاع لا ينتظر الشبكة.
- الحدود: الحماية على مستوى الواجهة (ليست DRM)؛ كافية لنموذج توزيع مباشر.
