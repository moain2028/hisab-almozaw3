# دليل استرجاع البيانات
| الموقف | الخطوات |
|---|---|
| حذفت التطبيق وأعدت تثبيته | افتح التطبيق، فتظهر "وجدنا X نسخة احتياطية"، اضغطها ثم اختر النسخة ثم **استبدال** |
| جوال جديد | (أ) لو فعّلت نسخ Google: البيانات تنتقل تلقائياً عند إعداد الجوال. (ب) أو انسخ مجلد `Android/media/com.hisabalmozaw3.distributor/Backups` للجوال الجديد بنفس المسار، ثم افتح التطبيق. (ج) أو نزّل ملف `.hisab` من واتساب، ثم: المزيد ← النسخ الاحتياطي ← استرجاع من ملف آخر |
| حذفت شيئاً بالخطأ الآن | اضغط **تراجع** في الشريط السفلي خلال 5 ثوانٍ |
| حذفت شيئاً بالخطأ أمس | المزيد ← النسخ الاحتياطي، ثم اختر نسخة أمس ثم **استبدال** (تُحفظ نسخة أمان من الوضع الحالي تلقائياً) |
| استرجعت نسخة خاطئة | اختر الملف `hisab-before-restore-…` ثم **استبدال** |
| "الملف تالف" | الملف تغيّر أو انقطع أثناء التنزيل. جرّب نسخة أخرى. التطبيق لا يسترجع ملفاً تالفاً أبداً |
