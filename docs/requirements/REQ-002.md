# REQ-002 — الأداء والنسخ الاحتياطي ومراجعة UX
## معايير القبول
- [x] حسابات الإطار < 2ms على سنتين من البيانات (اختبار آلي).
- [x] نسخ احتياطي تلقائي محلي يبقى بعد حذف التطبيق، بدون أذونات.
- [x] التحقق من سلامة النسخة قبل الاسترجاع، ونسخة أمان قبل الاستبدال.
- [x] تراجع بعد الحذف، وتنبيه الخروج بدون حفظ.
- [x] تباين الألوان ≥ 4.5:1.
- [x] توثيق كامل ومستودع منظم.
