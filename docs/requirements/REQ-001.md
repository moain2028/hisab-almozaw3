# REQ-001 — المتطلب الأساسي (من صاحب المشروع)
> "يوزّع الصبح على البقالات زبادي وحقين... ياخذه من التاجر بيومية (ما عنده مخزن)، وبعده الليل يتحاسب من البقالات ويحاسب التاجر الصباح وياخذ بضاعة. الهدف: يسجّل كم أعطى للبقالة كمية، ولما يتحصّل الليل يظهر له كم باقي عند صاحب البقالة."

## معايير القبول
- [x] تسجيل عطاء بكميات كسرية (¼ ½ 1) لكل صنف لكل بقالة.
- [x] عند التحصيل يظهر: السابق + عطاء اليوم − المرتجع = المطلوب، ثم الباقي بعد الدفع.
- [x] حساب التاجر: استلام صباحي + دفعات + إرجاع.
- [x] لا مخزن: "البضاعة في السيارة" ليوم واحد فقط.
- [x] يعمل بلا إنترنت.
